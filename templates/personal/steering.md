# Steering

This layer is **yours** and **gitignored**. An empty steering file is fine.

Before editing, read `context-files.md` in the `coaching-session` skill.

## Overrides

Where you relax, tighten, or contradict a tracked rule. State the rule and the override.

- _e.g._ Z2 NP cap → allow up to **72% MAP** this block (rebuilding threshold; accept more Z3 bleed).
- _e.g._ Two-a-days → also OK on Tuesdays this month (working from home).

## Additional emphasis

Steering that _adds_ to the philosophy without contradicting it.

- _e.g._ Bias slightly more volume over intensity while chasing durability.
- _e.g._ Extra attention to standing-start mechanics.

## Experiments

Things you're trialling that aren't yet beliefs. Promote to the philosophy skill if they stick;
drop them if they don't.

- _e.g._ Testing 3× short VO₂ pre-loads before the main set.
